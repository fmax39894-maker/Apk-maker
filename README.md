# Advanced HTML → APK Maker V2

This version fixes the misleading "project ZIP only" behavior and gives detailed backend errors.

## Render
Deploy the whole repository as a Docker Web Service.

- Runtime: Docker
- Port: 10000
- Health check path: `/health`
- Start command: leave blank (Dockerfile supplies it)

After deployment, first open:
`https://YOUR-SERVICE.onrender.com/health`

You should see JSON with `"ok":true`.

Then open the home page, select `index.html`, and press **Build APK**.

## If Build APK still says "Failed to fetch"
This is almost always a server/container failure, not a package-name problem.

Open Render → your service → **Logs** and look for:
- `[BUILD]`
- `[GRADLE]`
- `[FATAL]`

The webpage now displays the server response instead of hiding it behind "Failed to fetch".

## Important
A debug APK is generated by Gradle. It is not signed for Play Store release.
Render CPU/RAM/build-time limits can affect Android compilation.
