# Advanced HTML → APK Maker

This is a real server-side HTML-to-Android APK builder.

## Deploy on Render
1. Create a GitHub repository and upload this entire folder.
2. In Render, create a **Web Service** from the repository.
3. Choose **Docker** as the runtime. Render will use the included Dockerfile.
4. Set the health check path to `/health` if available.
5. Deploy.
6. Open the generated Render URL and upload an `index.html`.
7. Press **Build APK**.
8. Download the generated debug APK.

## Important
- The backend contains Android SDK + Build Tools + Gradle in the Docker image.
- A debug APK is generated by Gradle. It is not Play Store-signed.
- Package names are automatically sanitized. For example `My Science App` becomes a valid package such as `com.htmlapk.my.science.app`.
- The uploaded HTML is temporarily stored on the server during the build and cleaned after the build. The returned APK is removed after download/expiry.
- Large apps may exceed hosting CPU/RAM/time limits. Render plan limits apply.
